HOW TO USE THESE FILES WITH META AI

Every line of chat dialogue in Moonlit Meadows is here, 766 lines in all, one file per voice.
Send each file to Meta AI one at a time, copying everything inside it.

  01-Music.txt ............... background music (already done, you can skip it)
  02-June.txt ................ June, 60 lines
  03-Roz.txt ................. Roz, 58 lines
  04-Theo.txt ................ Theo, 59 lines
  05-Kai.txt ................. Kai, 58 lines
  06-Sol.txt ................. Sol, 56 lines
  07-Wes.txt ................. Wes, 39 lines
  08-Bree.txt ................ Bree, 36 lines
  09-Vi.txt .................. Vi, 38 lines
  10-Farmer.txt .............. your farmer, 116 lines. Record each twice: female (-F) and male (-M)
  11-Narrator-part1 to 4 ..... the storyteller voice for scene descriptions, 240 lines
  12-Intro-Narrator.txt ...... the storyteller's lines in the opening story, 5 lines
  13-Intro-Host.txt .......... the woman with the lantern at the gate, 1 line

Inside each file, the lines are grouped under titles like ==== Everyday chat ==== or
==== Story chapter 2 ====, so you can see where each line is used. The titles aren't read aloud.

If a file is too long for Meta AI, paste part of the LINES at a time, and keep the header
(the character, voice and rules) at the top each time.

IMPORTANT: name each audio file exactly with its ID, like JUNE-DAILY-EARLY-1.mp3 (and
JUNE-Q1-ANSWER1-F.mp3 / JUNE-Q1-ANSWER1-M.mp3 for the farmer). That's how the game knows which
clip goes with which line, so I can connect them all automatically when you send them back.

Lines that mention "this little one" are where the game says your bunny's name. A recorded
voice can't say every name, so the voice says "this little one" while the text on screen still
shows the real name.

ALL-IN-ONE.txt has every file above in one place, separated by big dividers, if you'd rather
scroll through one file.
