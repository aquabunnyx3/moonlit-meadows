VOICE SCRIPT: Rude answers and replies (new)

Please create voice lines for a cozy, pastel pixel-art farming game called Moonlit Meadows.

These are the new RUDE answer choices and how each character reacts. Use each character's SAME voice as their main script file. The farmer says the rude line flatly or a little dismissively; the characters react hurt, quiet, or awkward. Still gentle, never angry.

RULES:
- Read only the text in quotes. Do not read the ID or the note.
- Make one separate audio clip per line, named with its ID (for example JUNE-Q1-REPLY4.mp3).
- Farmer lines: record twice, female (-F) and male (-M), for example JUNE-Q1-ANSWER4-F.mp3.
- Lines like ==== June ==== are section titles. Do not read them.
